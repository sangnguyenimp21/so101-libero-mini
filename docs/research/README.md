# Background research (2026-10-16)

Reports written by parallel research agents before the implementation; kept as reference. They describe the state
*before* this project's code existed, and some paths they mention (scratchpad clones) no longer exist.

- [lerobot-api.md](lerobot-api.md): LeRobot 0.4.2 dataset / training / inference APIs as installed (torchcodec
  broken in the image, `add_frame` rules, ACT/Diffusion/SmolVLA defaults, the inference loop).
- [libero-design.md](libero-design.md): how LIBERO specifies tasks, samples initial states, checks goals and
  evaluates; what to copy and what not.
- [so101-model.md](so101-model.md): Menagerie vs TheRobotStudio SO-101 MJCF, jaw geometry, workspace, mapping to the
  real LeRobot follower.
- [prev-project-review.md](prev-project-review.md): skeptical review of the earlier lerobot-mini-project (expert
  targets unreachable poses, unrealistic grasp forces, lenient success, results found in its logs).
